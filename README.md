## Featured projects

### [MeloShelf](https://github.com/Danieljucke/MeloShelf)

A local-first Windows music organizer for identifying tracks, completing metadata, and safely arranging audio libraries. Built with Python, FastAPI, SQLite, Chromaprint, AcoustID, and MusicBrainz; the project includes recovery journals, SHA-256 verification, tests, documentation, and a Windows release.

### [Media Duplicate Finder](https://github.com/Danieljucke/Media-filter)

A Python and Tkinter desktop tool for reviewing visually similar images and videos before deletion. It combines perceptual hashing, Pillow, and OpenCV while keeping destructive actions explicit and user-confirmed.

### [Deezer to Spotify](https://github.com/Danieljucke/DeezerToSpotify)

A focused Python utility that reads public Deezer playlists, searches Spotify, creates a destination playlist, and reports unmatched tracks. It uses the Deezer and Spotify APIs through Requests and Spotipy.

### [SpotiFilter](https://github.com/Danieljucke/SpotiFilter)

A Python command-line tool for examining a Spotify library and creating genre- or region-based playlists. It handles OAuth credentials through environment variables and avoids duplicate additions.
